User Journey — แท็บ Encryption

  1. ใส่ข้อความลับใน Plaintext (หรือ Drag & Drop ไฟล์ / กด Browser)
  2. ใส่ Password ในช่อง Key (แสดงเป็น ●●● อัตโนมัติ)
  3. ใส่ข้อความปกปิด (ข่าว, รายงาน ฯลฯ) ในช่อง Covertext
  4. กดปุ่ม Encryption → Ciphertext (Base64) ปรากฏ + sync ไปแท็บ 2 อัตโนมัติ

User Journey — แท็บ Steganography

  1. Ciphertext sync มาอัตโนมัติจากแท็บ 1 (ไม่ต้องทำอะไร)
  2. Status Bar แสดง bits ที่ต้องการ + ความจุ ZWSP/NBSP
  3. กดปุ่มเทคนิคที่ต้องการ → sub-form เปิดขึ้นเพื่อเลือก options
  4. เลือก options → กด ตกลง
  5. Steganotext ปรากฏ → กด Copy หรือ Save
Decryption

User Journey — แท็บ Decryption

  1. วาง Steganotext (หรือ Drag & Drop ไฟล์)
  2. ใส่ Password เดิม (หรือกด Paste)
  3. กดปุ่มเทคนิคเดียวกันกับที่ใช้ตอนซ่อน → เลือก options เดิม → ตกลง
  4. ข้อความลับปรากฏใน Plaintext
  5. กด Copy / Save Plaintext

* ปุ่ม Decryption (แดง) = ถอด AES โดยตรงจาก Base64 (ไม่ผ่าน extract)

Zero-Width Space — ฝังข้อมูล
✕
Zero-Width Space (ZWSP)
เทคนิคนี้แทรก U+200B ระหว่างตัวอักษร
bit 1 = แทรก ZWSP, bit 0 = ไม่แทรก

Covertext ที่ป้อน: 142 ตัวอักษร (141 slots) — รองรับได้สูงสุด 141 bits
หลักการทำงาน:
• ฝัง: วนผ่านทุกช่องระหว่างตัวอักษร
  - bit=1 → แทรก ZWSP (U+200B)
  - bit=0 → ไม่แทรกอะไร
• ถอด: ตรวจช่องว่างระหว่างตัวอักษร
  - มี ZWSP → bit=1, ไม่มี → bit=0
Non-Breaking Space — ฝังข้อมูล
✕
Non-Breaking Space (NBSP)
เทคนิคนี้แทนที่ช่องว่างปกติ (U+0020) ด้วย Non-Breaking Space (U+00A0)
bit 1 = NBSP, bit 0 = space ปกติ

Covertext ที่ป้อน: 142 ตัวอักษร (18 spaces) — รองรับได้สูงสุด 18 bits
หลักการทำงาน:
• ฝัง: วนผ่านทุก space (U+0020) ใน covertext
  - bit=1 → แทนที่ด้วย NBSP (U+00A0)
  - bit=0 → คง space ปกติไว้
• ถอด: ตรวจสอบแต่ละตำแหน่ง space/NBSP
  - NBSP → bit=1, space ปกติ → bit=0
Synonym — คำพ้องความหมาย — เลือกกลุ่มสำหรับฝัง
✕
คำพ้องความหมาย (bit 0 / bit 1)
คำซ้าย = bit 0  |  คำขวา = bit 1  (เลือกกลุ่มที่ปรากฏใน covertext)
